Tongjin Google Docs CLI

A personal desktop command-line integration maintained by Tongjin for operating Google Docs through Google Workspace CLI (gws). This website provides application and privacy information. It does not collect document contents or offer a hosted document editor.

Purpose and Google API Access

The local tool reads, creates, appends to, and updates Google documents on the account holder's instructions. It can list and export Drive files authorized for this application.

  • The Google Docs permission allows document operations.
  • The drive.file permission allows operations on specific files used with the application.
  • Basic profile and email permissions identify the authorized account.
  • Offline access lets the desktop tool refresh access tokens without repeated sign-in.

Personal Desktop Use

The integration runs on the account holder's computer. OAuth credentials are stored locally in encrypted form. The tool can be invoked directly or through a user-authorized AI assistant. This is a personal integration, not a Google product or a public service.
